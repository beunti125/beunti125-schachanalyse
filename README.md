# Schachanalyse

Mac-App, die chess.com-Partien mit Stockfish 19 analysiert: Spielbericht mit Zugbewertung,
Trainer mit Erklärungen, eigene Varianten, Fehleranalyse und Taktikaufgaben aus eigenen Fehlern.

Die App prüft bei jedem Start dieses Repository (`version.json`) und aktualisiert Oberfläche
und Server automatisch. Die Engine-Dateien (`web/engine/`) sind nicht im Repository und
bleiben lokal in der App.

Lizenzen der verwendeten Bausteine: siehe `web/LIZENZEN.txt` (Stockfish: GPLv3).
